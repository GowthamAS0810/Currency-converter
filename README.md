# 💱 Real-Time Currency Converter

A clean, responsive, and dynamic web application built using **React** to convert currencies in real-time. This project interacts with a public currency API to fetch live, up-to-date exchange rates.


## ✨ Features
* **Live Exchange Rates:** Fetches real-time, accurate conversion rates using a public API.
* **Instant Conversion:** Updates calculations instantly as the user types or switches currencies.
* **Responsive Design:** Designed with semantic HTML and custom CSS to look great on desktop, tablet, and mobile devices.
* **User-Friendly UI:** Intuitive dropdown menus for seamless currency selection.

## 🛠️ Tech Stack & Tools
* **Frontend Library:** React.js (Functional Components, Hooks)
* **Markup & Styling:** HTML5, CSS3 (Flexbox/Grid, Custom Variables)
* **API Integration:** Fetch API / Axios for handling asynchronous network requests
* **Data Provider:** Public Currency Exchange Rate API



## 🧠 Key Learning Outcomes
* React State & Effects: Learned how to manage dynamic data using useState and handle API synchronization using the useEffect hook.
* API Integration: Gained hands-on experience fetching real-time JSON data from a third-party REST API and rendering it dynamically.
* Asynchronous JavaScript: Practiced working with promises and async/await functions to manage network requests smoothly.
* Problem Solving: Learned how to implement error boundaries and loading indicators to handle network delays or failed API responses
* Writing clean, component-based frontend code.
